# Agent Note: 验证既有种子会话查询，不套用新建规则

Status: implemented

[English](2026-09-10-seeded-session-query.md) | 中文

## 问题

精确查询验证将完整既有子会话历史传入新建 Session 流程。包含自身事件的子会话超过其继承前缀，即使迁移和恢复成功也会被拒绝。

## 实现

在可复用 session-query 包中落实 [Accepted 查询决策](../../../../docs/decisions/20260910-seeded-session-query-restoration.zh.md)：创建无损 JSON 验证副本、执行分离恢复验证，并将未改变的已加载快照作为公开结果。保持有效的新建分叉不变量与存储所有权不变。

## 已考虑的替代方案

削弱构造器、截断事件或清除继承会掩盖损坏。返回恢复额外添加的事件会改变精确读取。此次有界修复不需要通用验证服务。

## 验收标准

证明实时/冷种子会话查询、结果分离所有权、不产生生命周期或存储字节变更、严格拒绝无效输入，以及真实已交付子会话的迁移/重启/恢复链路。工作项负责实现准入与资格限制。

## 风险

恢复流程不能独立证明输入是无损 JSON，并可能在内存中添加 end-seed 标记。查询所有者必须明确保留这两项检查。记录这项可复用修复，以供单独授权的上游贡献。
