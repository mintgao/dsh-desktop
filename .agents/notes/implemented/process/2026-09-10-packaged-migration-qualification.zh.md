# Agent Note: 将迁移资格绑定到实际打包执行证据

Status: implemented

[English](2026-09-10-packaged-migration-qualification.md) | 中文

## 决策

[Accepted 集成决策](../../../../docs/decisions/20260910-desktop-mint-target-integration.zh.md)及其固定场景表约束迁移资格。真实且未验证的源码评估允许采用；发布还要求完整且分别绑定架构的打包报告。源码测试结果不能替代正常原生行为。

## 实现

资格验证器认证已交付基线、精确候选检出和 DMG、实际打包运行时、完整内置组合及保留证据。每个场景选择自身实际执行的断言。原生夹具保留产品沙箱并使用一次性 runner 账户；能力缺失会拒绝资格。提升与保留证据恢复重新验证报告载荷；撤回仍可隐藏精确损坏版本。

## 验证

聚焦的解析、祖先关系、恢复、进程清理和调试器协议回归，配合真实隔离打包后端的迁移、重启及完整备份恢复。无密钥 persona／种子查询场景记录作用域内模型可见输入及冷查询输出。正常原生 UI、Shell 支持及双架构生产报告仍是受保护 CI 的执行门槛；本地开发收据明确不具备发布资格。

## 替代方案

重标记冻结的源码评估或跨架构共享不透明载荷会丢失来源。重写用户创作数据或让基线读取升级后的根目录会使恢复失效。保留的字节清单在成功合成夹具清理前绑定实际备份及新版副本；失败时保留诊断数据。
