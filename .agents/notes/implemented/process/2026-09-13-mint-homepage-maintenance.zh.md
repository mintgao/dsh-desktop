# Agent Note: Mint 首页与发布要点

Status: implemented

[English](2026-09-13-mint-homepage-maintenance.md) | 中文

## 问题

桌面用户需要下载入口、平台支持信息和有用的发布要点。以上游为主的介绍，以及仅在另一页面提供的发布历史，会掩盖 Mint 应用本身，并让安装建议偏离公开产物。

## 决策

根目录 README 配对文档展示 Mint 品牌、项目状态、安装方法和最新已发布 Desktop 要点。[首页维护规则](../../../../README.zh.md#homepage-maintenance)定义发布负责人的职责和发布顺序；[项目规则](../../../../.vibe/project-rules.md)将其纳入后续任务上下文。[下游开发决策](2026-08-24-mint-desktop-downstream-development.zh.md)继续负责仓库与发行身份。

## 考虑过的替代方案

**只在 Releases 中记录更新。** Releases 仍保留完整历史，但访问者无法直接在项目首页了解当前桌面版本。

**把每项上游变化都复制到首页。** 这会淹没 Desktop 改进，并可能在 Mint 产物公开前暗示功能已可用。精选用户可见的要点能保持桌面版重心。

## 验证

翻译配对和文档检查验证配对记录一致及链接有效。发布审查依据公开版本核对版本号、日期、产物和用户可见描述；Markdown 检查本身不能证明功能可用。

## 后果

发布负责人在每次相关发布时维护简短的双语摘要。这是必需的编辑步骤，并非自动发布说明生成器；不影响用户的内部变化无需列入。
