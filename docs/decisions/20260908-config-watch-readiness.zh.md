# 确切配置监听器的就绪行为

[English](20260908-config-watch-readiness.md) | 中文

Status: Accepted

## 范围与证据

该支持性修正服务于桌面实时配置补丁启动及[交付验证](../work-items/20260908-desktop-reviewed-delivery/brief.zh.md)。可控且有限的线程池争用证明 Chokidar 轮询存在就绪缺口：注册后创建的文件被初始轮询基线吸收，争用结束十秒后仍未观察到。默认 Chokidar 轮询不能建立所承诺的配置就绪行为。失败候选不是发布证据。

## 管理轮询基线

确切配置的轮询模式使用注册项管理的单一目标采样器替代 Chokidar。同一注册项不能同时运行两套实现。显式原生模式及模块监听保留其实现。通过已有规范化路径逻辑解析别名及重复身份，在异步初始化前登记资源归属。

注册完成前，等待规范化目标的首次 stat。成功观察结果为缺失，或包含文件身份、类型、大小、修改时间及变更时间的指纹；时间字段采用 bigint。目标采样时的 ENOENT 和 ENOTDIR 表示缺失，包括缺失路径组件。保留初始祖先校验失败。其他初始 I/O 错误拒绝注册并清理。

返回前记录初始观察结果并启动调度器。初始存在的目标仅提交一次已有初始刷新。后续不同观察结果通过已有串行及合并的 refreshConfig 路径提交刷新；相同结果不刷新。注册后的持久创建与已经记录的缺失状态比较。就绪不依赖原生确认、哨兵、第二次启动扫描或启动延迟。

## 调度与配置

每个注册项管理一个计时器，同时最多一个目标采样在执行。前一次采样结束后才安排下一次。慢 I/O 不能积累读取任务；间隔控制采样频率，不承诺墙上时钟交付期限。

实际后端按支持的环境覆盖、配置的 usePolling、修正后的确切配置默认值顺序显式解析。初始化前校验实际选项。采用经过校验的 interval，包含其支持的环境覆盖，保留已有 100 ms 默认值。确切目标采样使用统一间隔；binaryInterval 仍作为 Chokidar 选项用于继续采用它的路径。模块默认值保持不变。

每个循环只执行一次目标路径 stat，没有目录订阅或枚举。默认调度每秒最多十次循环采样，受调度及 I/O 延迟影响；初始设置另计。规范化路径解析需要文件系统遍历。不宣称 CPU 开销可忽略。移除只用于轮询的祖先及过滤机制；保留原生路径过滤及已有别名。初始锚点删除仍不属于已验证的恢复承诺。

## 错误与释放

后续意外采样错误不视为缺失，也不替换最后一次成功指纹。通过已有配置失败语义报告，同时保留最后一个有效应用状态。连续等价采样错误去重；后续采样能够观察恢复。回调失败不触发自动刷新重试。

关闭时先标记注册项停止，再取消计时器。等待仍在执行的初始或循环采样，阻止其稍后完成时提交刷新，随后排空已进入队列的刷新任务。全局 HMR 释放使用相同关闭操作。初始化拒绝、初始化期间释放及普通释放均不能遗留可产生延迟回调的计时器或读取。

## 验收

保留现有及缺失父目录下立即单次创建的回归用例，省略后端选择。阻塞首次采样，证明注册尚未完成；返回缺失后，在注册完成后创建一次，并在不使用 fs.watch 或 fs.watchFile 时观察刷新。阻塞循环采样，证明读取不能重叠。初始及循环采样期间释放，拒绝延迟提交。覆盖初始存在文件、增改删、替换、别名、缺失组件、错误及恢复。

分别包含零个与 100 个无关同级条目的等效根目录，目标采样数量必须相同，没有目录轮询，释放后没有归属任务。还原基线归属必须使可控回归失败。重复针对性主机并发检查，再对修正候选执行独立完整验证。

将串行化夹具的固定 250 ms 假设替换为第二次刷新实际进入队列的信号。保持第一次回调阻塞，证明第二次刷新进入队列，开始释放并证明其尚未结束，随后放行第一次回调，保留确切的 `['one', 'two']` 观察断言。这修复夹具同步，不削弱产品释放语义。

## 归属与移除

可复用的 vendor HMR 插件负责修正，配套针对性启动测试及消费者文档。保留独立支持性提交，更新 [vendor 修改记录](../../vendor/README.md#local-modifications)，保留上游固定版本。未来同步时，只有上游通过等价的显式基线、资源及生命周期回归，才能移除本地补丁。本决策不授权上游提交、模块监听重设计或公开发布。

## 分离 I/O、清理及通知

原始文件系统操作与初始化 Promise、错误通知分开跟踪。原始路径解析及采样在完成时不执行清理，也不等待监听者或释放。处理结果前清除在途归属，随后检查停止状态，再决定是否插入注册项、提交刷新、报告错误或安排采样。

初始失败在幂等清理后拒绝注册。清理可以等待原始 I/O，不能等待调用清理的初始化 Promise。并发释放共享一个关闭操作。规范化解析期间释放会标记初始化停止并等待原始解析；解析完成后拒绝初始化，不启动首次 stat，也不插入注册项。规范化身份明确后，在采样前预留注册归属。

采样错误通知仅在原始采样完成并解除在途归属后开始。监听者可以发起并等待 HMR 释放。关闭等待原始 I/O 及已提交刷新，但不等待采样错误通知派发；服务关闭也必须保留该排除。跟踪通知 Promise 至完成，收敛拒绝并移除已结束报告。已开始的监听者可以在关闭后完成，但不能安排采样、提交刷新或改变注册状态。这不改变刷新回调串行化。

测试初始 stat 拒绝与释放并发、错误监听者等待释放、规范化解析阻塞期间关闭、关闭后通知拒绝收敛，以及并发关闭共享完成。注册拒绝及释放必须结束，不能等待自身，也不能稍后启动初始采样、注册项、计时器或刷新提交。
