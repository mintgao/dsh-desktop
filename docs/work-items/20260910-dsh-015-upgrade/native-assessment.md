## Current authority

The native and data proposals are resolved by the [Accepted Mint integration decision](../../decisions/20260910-desktop-mint-target-integration.md) and [normative composition and scenario registry](../../decisions/20260910-desktop-mint-migration-registry.md). The registry takes precedence for exact composition, mandatory scenario IDs and report fields. Technical authors are `upgrade_native_assessment` and `upgrade_decision`; `classification_review` independently approved the design. The [review record](phase-b-design-review.json) binds the original artifacts by digest.

The direct-upgrade and restore baseline is the actual delivered `desktop-v0.1.2-alpha.3.unsigned.1`, downstream `67406fc6af451f7f68874cb31c2d0f3242c0c8ad`. The earlier policy checkout is not a substitute for that delivered runtime. Target remains `b2e3b2a0125854567a4a5fcba75782e42fe84901`.

## Remaining evidence

Design acceptance does not certify a candidate. The [work-item readiness record](brief.md) requires orchestrator confirmation before application/shared implementation begins. Packaged arm64/x64 direct upgrade, complete store and settings scenarios, backup/restore, exact runtime identity and independent default verification remain unexecuted qualification obligations. No native application was launched or user data accessed during design persistence. Merge, publication and installed-app replacement are separately authorized operations.
