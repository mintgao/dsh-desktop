## 备选方案与决定

原紧邻后继策略要求分别采纳源码，并建立完整桌面交付链。源码准备和公开交付是不同要求；假设的本地锁无法满足受保护主分支祖先关系或发布谱系。

所有者选择显式追赶：一次已审核源码采纳 PR 和一次桌面交付，同时保留完整上游祖先、范围审核和直接升级证据。工具前提与实际源码采纳保持分离。[原生评估](native-assessment.zh.md)记录尚待处理的 Phase B 问题。
