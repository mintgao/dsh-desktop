# 以已发布前向清单作为追赶升级前驱

[English](brief.md) | 中文

## 范围与证据

规模：S，已接受发布约定内的局部读取一致性修复。真实公开 alpha.2 unsigned.2 清单使用 schema 3。RC.2 采用规划拒绝该下载清单，因为追赶升级前驱读取器仅接受 schema 1 和 2。发布和清单验证器已经接受 schema 3。[已接受的前向决策](../../decisions/20260913-observed-forward-delivery.zh.md)将 schema 3 定义为最终发布清单；不引入新格式、权限、运行时或迁移语义。

## 技术就绪

仅扩展追赶升级前驱读取器支持的最终清单版本枚举。保留精确公开最新版本、仓库、发行标识、模式、下载 JSON 和不可变标签身份检查。测试接受已发布 schema 3 和历史 schema 1/2，拒绝未知版本、构建收据、影子模式、被修改下载和移动标签。独立 Tech Lead 依据已接受的前向决策批准此范围。仅接受数字 schema 1/2/3，拒绝字符串版本。门禁负责人：root；implementation-ready。root 是唯一实现写入者；QA 保持独立。宿主无法恢复此前 RD 专家，因此 root 使用顺序 RD 回退。

## 交付

通过普通受保护主分支 PR 流程合并此工具修正，再由受信任机器人最终确认 RC.2 源码采用。不改变 source-lock 或已发布产物。针对更新后的受保护基线重新规划 RC.2 采用并保留源码祖先。用户的发布授权包含此必要修复；不得绕过保护。
