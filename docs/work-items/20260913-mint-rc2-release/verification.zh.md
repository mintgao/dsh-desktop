# 验证：Mint RC.2 发布

[English](verification.md) | 中文

## 已验证源码范围

独立审核确认官方 alpha.2、RC.1 和 RC.2 的持久化实现文件完全一致。发布准备 CLI 接受两个精确 Mint 包目录的独立版本，同时保留官方版本不匹配的拒绝检查。对应真实 CLI 回归测试通过。[组装验收](../20260913-desktop-versioned-assembly/verification.zh.md)负责未变化运行时的证据。

## 本地前驱升级

独立原生 QA 用精确的公开 alpha.2 unsigned.2 应用建立私有测试数据，随后运行未变化的本地 RC.2 应用并正常重启。历史可在各阶段继续；九项已有设置、配置档案和工作区文件逐字节不变。三次正常退出均无残留进程，使用后验证接受全部 25,484 个打包文件。[摘要绑定证据](../../../.github/desktop-delivery/rc2-local-upgrade-evidence.json)记录产物身份和限制。

## 平台选择验证

已批准的平台选择检查器接受同一份未修改官方锁的两种真实安装：npm 10 安装 522 个包，npm 11.19 安装 520 个包。每个已安装包都通过经完整性认证的完整载荷比较。篡改保留的可选包会被拒绝。聚焦测试覆盖已选包缺失、损坏或不一致清单、共享必需路径、嵌套及作用域依赖、循环和平台选择器。冻结锁 SHA256 保持为 `afa439f37a8b544b3884460a10634c6b474736958942aa4543ea048a95d348df`。独立最终候选验证及真实 CI 平台验证仍是单独的发布检查。

## 交付验收

最终 CI 产物升级、受保护的源码最终确认、精确发布产物验证、公开资产核验、本机客户端替换和清理仍待完成。此报告不代表发布或安装成功。发布负责人在逐项观察结果后记录最终公开和本机验收。
